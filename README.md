# EventHub
Event Management and Registration System

## Project Overview
EventHub is a web-based application designed to simplify the management of university workshops, seminars and student activities. It allows participants to discover and register for events, while organizers can create events and manage registrations.

## Planned Features
- User registration and login
- Participant and organizer roles
- Event creation and management
- Event browsing and search
- Event registration and cancellation
- Capacity management
- Organizer dashboard
- Waiting list (optional)

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: SQLite
- Version Control: Git and GitHub

## Software Development Process
The project follows an Incremental and Iterative development approach.

EventHub follows a layered architecture with a modular monolith structure.
